# JEL

Modern donation application built with Kotlin and Jetpack Compose.

## About
JEL is a mobile donation platform that allows users to support people and organizations easily.

## Features
- User authentication
- Donation categories
- Online payments
- Donation history
- Push notifications

## Tech Stack
- Kotlin
- Jetpack Compose
- Hilt
- Retrofit
- Room
- Ktor Backend

## Architecture
MVVM + Clean Architecture
